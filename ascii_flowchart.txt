  [Action]  (actions/MFP_action.H/.cpp)  -- a PHYSICS OPERATOR that advances states.
   |  Decoupled from data:  State holds data, Action computes the change (dU).
   |  Binds to states via state_indexes[];  interface (the "action contract"):
   |     get_data()              fill working copy U (+ghosts) from state, zero dU
   |     calc_time_derivative()  dU += point-local source terms        (accumulating)

 4. THE TIME-ADVANCE LOOP  (heart of the solver)   Source/MFP_advance.cpp
================================================================================

  MFP::advance(time, dt, iteration, ncycle)              [called per level by AMReX]
    |
    |-- for each state:  allocOldData(); swapTimeLevels(dt)   (old <- new)
    |-- copy old -> new for every Eulerian state ; reset flux registers
    |
    |-- switch (time_integration_scheme):                (MFP::TimeIntegrator)
    |       RungeKutta      -> advance_RK()
    |       StrangSplitting -> advance_strang()
    |       Symplectic      -> (no-op here; all work in apply_change)
    |
    |-- for each action:  apply_change(this,time,dt)     <-- Elliptic projection,
    |                                                        Symplectic PIC run here
    `-- Lua garbage collect

  -- advance_RK (SSP-RK, the canonical pattern) -------------------------------
     Vector<UpdateData> RK_step  (one slot per Eulerian state, keyed by data_idx)
          struct UpdateData { MultiFab U; MultiFab dU; Status U_status, dU_status; }
                              ^^^^^^^^^^^^^^^^^^^^^^^^  <-- THE per-step working
                                                            data object (Sec 5)
     STAGE 1 (RK1 / Euler):
        for each action:  get_data        -> fill U (FillPatch w/ ghosts), zero dU
                          calc_time_derivative      -> dU += sources(U)
                          calc_spatial_derivative   -> dU += -div(flux)  (+flux regs)
        new = old + dU                                (per state with dU "Changed")
     STAGE 2 (if nsteps>=2):
        re-get_data at time+dt (refills ghosts) ; recompute dU
        new = 0.5*old + 0.5*(U1 + dt*dU1)             (SSP-RK2 combine)
     ONE-SHOT:
        for each action:  apply_time_derivative ; apply_spatial_derivative
                          (e.g. tracer particle push -> writes new data directly)

  -- advance_strang  ----------------------------------------------------------
     Operator splitting:  half-dt SOURCES  ->  full-dt FLUX/TRANSPORT  ->  half-dt SOURCES
     (same get_data/calc_*/apply_* calls, reordered around the flux sub-step).

  -- Per-EulerianState flux machinery invoked inside calc_spatial_derivative ---
     get_new_data(data_idx)  [conserved MultiFab]
        -> calc_primitives  -> update_boundary_cells
        -> reconstructor.calc_reconstruction (slopes, ghost width = num_grow)
        -> update_face_prim / face_bc
        -> flux_solver.calc_fluxes (Riemann) [+ shock_detector] [+ viscous fluxes]
        -> (EB) calc_wall_fluxes, calc_eb_divergence, merge small cut cells
        -> divergence -> dU

  TIMESTEP (MFP_timestep.cpp):
     estTimeStep() = cfl * min( all state->get_allowed_time_step(),
                                all action->get_allowed_time_step() )    [reduced over MPI]
     computeInitialDt / computeNewDt feed AMReX's sub-cycling.

  POST-STEP (MFP.cpp):
     post_timestep -> reflux (flux registers) + avgDown (fine->coarse) + particle redistribute
     errorEst (MFP_refinement.cpp) -> each state->get_refinement_tags + user refine_boxes -> AMR regrid

 5. WHERE THE DATA LIVES  (memory model)
================================================================================

  THERE ARE TWO DISTINCT "DATA OBJECTS":

  (A) PERSISTENT solution state  -- owned by AMReX, NOT by the State classes.
      [MFP : AmrLevel]  registers descriptors in  static DescriptorList desc_lst.
      Each EulerianState's  data_idx  indexes AMReX StateData, holding old & new
      MultiFabs, fetched via  get_old_data(data_idx) / get_new_data(data_idx).
      Lagrangian states instead own  AmrParticleContainer particles  directly.
            State object = descriptor + numerics (small).
            AmrLevel     = the bulk grid data store (large), keyed by data_idx.

  (B) TRANSIENT per-step working set  --  Vector<UpdateData>  in advance_RK/strang.
      struct UpdateData { MultiFab U; MultiFab dU; Status ...; }   (actions/MFP_action.H)
      One {U,dU} pair PER Eulerian state, allocated fresh each advance() call,
      filled by get_data (U = state + ghost cells), accumulated into by every action,
      then folded back into new_data.   <-- This allocate-per-step, per-state working
      buffer is the data object whose memory handling is to be improved.

  Supporting per-level memory:  EBData (EB geometry arrays), flux_reg[] (flux
  registers for refluxing), level_mask (iMultiFab), Cost (load-balance MultiFab).

================================================================================
 7. ONE-LINE MENTAL MODEL
================================================================================
   Lua problem file  --(factories)-->  States (own descriptors/numerics) +
   Actions (own physics).  AMReX owns the AMR grids, sub-cycling time loop, and the
   persistent solution MultiFabs (keyed by data_idx).  Each step, advance() builds a
   transient Vector<UpdateData>{U,dU} working set, every Action accumulates its dU,
   and the result is folded back into the new MultiFab.
